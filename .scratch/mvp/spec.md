Shared API conventions: JSON objects use snake_case UUID string IDs; auth login returns {token,user:{id,email,role}}, roles ADMIN/USER/VIEWER. Authorization Bearer token. Collections return {items:[...],next_cursor:null|string}; event pagination also snapshot_id. Errors {code,message,request_id,details?}. Event creation {title,description,category,venue,sales_start,sales_end,zones:[{code,name,price_twd}]}; updates use If-Match version. Seat booking {seat_ids:[UUID]} OR {zone_id,quantity}, with Idempotency-Key. Payments {outcome:success|failure,delay_seconds?:number}, with Idempotency-Key. Imports use multipart file plus mode all_or_nothing|skip_invalid. Use /api/v1 routes specified in design; WS /ws/events/{event_id}, first frame {type:auth,token}.
